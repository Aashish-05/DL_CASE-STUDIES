# DL_CASE-STUDIES
Deep learning projects: MNIST digit recognition, CIFAR-10 CNN image classification, and Brain tumor detection with CAM. Includes data preprocessing, CNN/MLP models, training evaluation, and visualization.

1️⃣ MNIST Digit Recognition

Handwritten digit classification using the MNIST dataset.

Tasks Covered

Data loading and preprocessing

Neural network model design (MLP)

Model training and accuracy evaluation

Prediction interpretation

Dataset
MNIST dataset containing 70,000 grayscale images of digits (0–9).

2️⃣ CIFAR-10 CNN Classification

Image classification using a Convolutional Neural Network (CNN).

Tasks Covered

Data handling and preprocessing

CNN architecture design

Model training and performance evaluation

Visualization of results

Dataset
CIFAR-10 dataset containing 60,000 color images across 10 categories.

3️⃣ Brain Tumor Detection + CAM

Medical image analysis using CNN and Class Activation Maps.

Tasks Covered

CNN model implementation

Feature map and filter visualization

Class Activation Map (CAM) generation

Tumor localization and medical interpretation

Dataset
Brain MRI images used for tumor classification.
